插件简介：  
本插件通过检测游戏手柄通过Xinput接受的震动信息通过DGHUB联动DGLAB设备--实现“手柄震动郊狼放电”的效果  
快速配置说明：  
本项目采用分卷压缩上传，请下载"手柄震动联动.7z.001-003"3个压缩文件置于同一文件夹下，使用压缩软件解压。  
如解压遇见问题可用"手柄震动联动.exe"解压程序帮助解压。   
解压后复制压缩包"main.zip"，使用DGHUB软件导入该插件。  
配置：在配置页面配置好你要检测的游戏的进程名称，确认禁用steam输入。  
本插件支持Xinput手柄输入的游戏，具体兼容性有待考量。  
前置软件引导：  
DGHUB:http://www.dghub.top/  
DGLAB:https://dungeon-lab.cn/  
PS:本插件源代码放置于源代码分支；使用插件无需下载
